# BG Player

貼ったURL(YouTube / mp3・mp4・m3u8 / 端末のファイル)をバックグラウンドでも再生する無料のPWA。

## 公開(無料)
GitHub → Settings → Pages → Branch を選んで Save。表示されたURLをスマホで開き、
「ホーム画面に追加」(iPhone: 共有メニュー / Android: アプリをインストール)。

## 注意
- ファイル/直リンクはロック画面でも再生。YouTubeは公式埋め込みのため端末により画面オフで止まる場合あり(ベストエフォート)。
- ローカル確認: `python3 -m http.server` → http://localhost:8000
